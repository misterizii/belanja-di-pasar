# Petualangan Pasar Kedungadem

Game matematika SD berlatar Pasar Kedungadem. Buka di browser: https://misterizii.github.io/belanja-di-pasar/

## Pilihan permainan

| Permainan | Kelas | Isi |
|---|---|---|
| 🧕 **Ikut Ibu ke Pasar** | 3 | Menemani Ibu belanja dan menghitung benda di 6 kios: membilang per puluhan, nilai tempat, menaksir, penjumlahan & pengurangan, perkalian dan pembagian (hasil ≤ 100), lalu mengurutkan & membandingkan di buku harian. Level ⭐ sampai 100 atau ⭐⭐ sampai 1.000. |
| 🛒 **Belanja Sendiri** | 4 | Belanja dengan uang: harga, total, dan kembalian dalam ribuan. |

Keduanya bisa dimainkan **sendiri** atau **balapan berdua** di satu layar (cocok untuk IFP/layar sentuh). Angka diacak setiap kali bermain.

## File

- `index.html`, `style.css`: halaman dan tampilan
- `app.js`: menu, peta, dan mode Belanja Sendiri
- `engine.js`: angka dan soal Belanja Sendiri
- `story-data.js`: angka dan soal Ikut Ibu ke Pasar
- `story.js`: cerita, kegiatan menghitung, dan buku harian Ikut Ibu ke Pasar
- `race.js`: mode balapan berdua untuk kedua permainan
